# Загрузчики открытых объявлений

Для разработки и разового запуска регистрация в Timeweb не нужна. Python 3.11+ и Node.js 24. Python использует только стандартную библиотеку.

```sh
python3 monitor/collect.py --output /tmp/mydom-outages.json
OUTAGES_PATH=/tmp/mydom-outages.json DATABASE_PATH=/tmp/mydom.sqlite node server/server.mjs
```

Открыть http://localhost:8080 и выбрать адрес. GET `/api/outages` доступен без регистрации: файл содержит только публичные объявления и состояние источников. Файл нужно хранить вне публичного каталога сайта. Адреса пользователей сборщику не передаются.

Для постоянной работы запустить отдельный процесс под супервизором:

```sh
python3 monitor/collect.py --output /data/outages.json --watch --interval 1800
```

Серверу установить `OUTAGES_PATH=/data/outages.json`. Сборщик и сервер должны иметь доступ к одному файлу. Запускать только один экземпляр сборщика на файл. JSON заменяется атомарно. Для публикации необходимы постоянно работающая машина, исходящий HTTPS и прежняя настройка HTTPS приложения. На GitHub Pages Python/Node-процессы не запускаются; слияние PR само по себе не включает мониторинг. В существующем Node Docker-образе Python отсутствует: сборщик запускается отдельно, например образом из `monitor/Dockerfile`, с общим каталогом `/data`. Автозапуск в облаке пока не выполнен.

## Источники и границы реализации

- Россети: `https://www.rossetisk.ru/press_center/disconnects/`. Из четырёх последних публикаций выделяется раздел КБР, затем только Нальчик. Несколько временных интервалов становятся отдельными записями. Однозначная дата из адреса статьи интерпретируется в Europe/Moscow. При нескольких датах срок остаётся неуточнённым. Простой список улиц даёт совпадение улицы, но не подтверждение конкретного дома. Смешанные районы, СНТ и диапазоны остаются неразобранными; их текст доступен для проверки.
- Водоканал: публичная страница `https://t.me/s/mup_nalchikskii_vodokanal`. Разбор отдельных сообщений по `data-post`, тексту и дате публикации подготовлен. При проверке 09.10.2026 из текущей среды источник вернул `Site Unavailable`; полноценный сетевой запуск этого адаптера **не подтверждён**, требуется проверка с сервера. Обход ограничений не предусмотрен. Формат сообщений проверен синтетическими тестами.
- При нераспознанной странице/ошибке хотя бы одной статьи источник помечается ошибкой и сохраняет свою последнюю успешную подборку. Успешный пустой результат отделён от ошибки. Время последней проверки и последнего успеха сохраняется отдельно.
- Стабильные идентификаторы устраняют дубли повторного запуска; изменение текста/времени отмечается `changedAt`. Это **не** семантическое связывание отдельных сообщений о переносе, отмене и восстановлении. Такие сообщения не считаются автоматически подтверждением нового статуса, должны быть прочитаны в оригинале. Пропажа записи из последних публикаций также не означает восстановление.
- Карточки не блокируют обращение жильца и не отправляют аварийные push-уведомления. Истёкшее плановое время не подтверждает восстановление. Интерфейс показывает объявления с началом не старше суток, недатированные сообщения с публикацией не старше семи суток; объявления без извлечённых дат остаются с пометкой проверки.
- Полное покрытие аварий, геокодирование, координаты домов и границы территорий не реализованы этим сборщиком. Проверяется ограниченная текущая подборка, не весь архив.
