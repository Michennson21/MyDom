# Общая проверка — 0.37

Исправления:
- Главная учитывает подтверждённый статус обращения. Отправленные и зарегистрированные показаны как ожидающие ответа, полученный ответ предлагается проверить, решённые убраны из блока внимания. Сохранение и удаление обращения сразу обновляют главную.
- Завершение знакомства не скрывает ошибку сохранения: окно остаётся открытым с возможностью повторить.
- Регистрация service worker выполняется и после уже прошедшего события load.
- Установленный набор файлов приложения берётся из одного версионного кеша. Установка следующей версии заново запрашивает ресурсы, без принудительной активации поверх открытых вкладок. Уведомление предлагает закончить ввод и закрыть все вкладки. Данные localStorage не очищаются. API не кешируется.

Проверки:
- 27 модульных проверок: схема копий, суммы, месяцы, связи счетов, поставщики, QR, УК, сопоставление отключений, синтаксис.
- Браузерные сценарии: адреса и мобильная ширина; квартиры; главная; начисления; согласованность счётчиков; паспорта/поверки/календарь; обращения и экспорт/печать; маршрутизация обращений; статусы/черновики; безопасность хранения; серверная резервная копия; первый запуск; обновление и офлайн-режим.
- Отдельный браузерный тест с настоящим service worker проверяет две версии: ожидающее обновление, единый набор файлов, сохранение формы, активация после закрытия, офлайн-перезапуск и сохранность черновика.
- Первый запуск проверен с реальным выбором адреса, пропуском лицевого счёта, ошибкой сохранения и повтором, экспортом и импортом в чистый браузер.

Тесты интерфейса с подменой сетевых ответов запускаются без service worker; его жизненный цикл проверяет release-update.browser.cjs. Обновлены устаревшие ожидания теста адресов после переноса добавления квартиры в «Ещё» и асинхронного хранения.

Ограничения: Chromium, без физического iPhone/Safari. Это подготовка тестовой версии, а не подтверждение готовности платежей, интеграций и промышленного сервера. Пользователю нужно сохранить введённое и закрыть все вкладки для применения обновления. Очистка данных браузера по-прежнему требует восстановления из копии.
