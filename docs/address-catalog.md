# Адреса Нальчика: границы данных

Обновление 09.10.2026 использует открытый справочник https://kladr-rf.ru/07/000/001/000/?show_all_streets=1.
Это вторичный источник, а не полная официальная выгрузка ГАР. В списке получены 459 действующих адресных объектов, включая 49 садоводческих территорий. Записи с отметкой `old` и `del` не импортируются как новые действующие объекты. Существующие записи приложения сохраняются, чтобы ранее выбранные адреса оставались доступны.

Для каждой новой записи сохранены код, тип, ссылка на исходную страницу и дата загрузки. Домовые значения переносятся из раздела «Интервал домов» без выдумывания номеров. Интервалы не разворачиваются в гарантированно существующие дома. Наличие дома в этом справочнике не подтверждает его актуальность в ГАР, наличие квартиры или управляющую организацию.

Поиск поддерживает названия с типом/без типа, проспекты, переулки и привычное написание СНТ для территорий, указанных как СДТ. Тип в сохранённом адресе берётся из справочника. Участок/частный дом можно сохранить без номера квартиры. Поле «Улица» единое для городских улиц и СНТ. Отдельного поля внутренней улицы нет. Прежние составные адреса открываются целиком в этом поле и не теряются. Номер отсутствующего дома можно ввести вручную; такие адреса получают `addressSource: user`. Рублёвская добавлена по сообщению пользователя без выдуманных домов и без статуса ГАР; совпадение с улицей Рублёвка не предполагается. УК не назначается автоматически для полностью ручного адреса или пользовательской записи улицы.

Номера в выпадающем списке сортируются численно (1, 2, 10); служебные префиксы «двлд», «дмвлд», «зд» и подобные убираются. Буквы, дроби и номера корпусов сохраняются. Исходный снимок справочника остаётся неизменным. Сравнение квартир учитывает очищенный номер, чтобы повторный выбор старого адреса не создавал дубликат.

Полнота всех адресов Нальчика **не подтверждена**. Официальный endpoint выгрузки ФИАС во время работы возвращал HTTP 502. Следующий этап для подтверждённой полноты — региональная выгрузка ГАР (регион 07), обход иерархии Нальчика с территориями СНТ/СДТ, их улицами, домами и участками, проверка актуальности объектов. Этот этап не подменён ручным вводом.

Обновление:

```sh
python3 scripts/refresh-addresses.py
python3 scripts/build-address-catalog.py /tmp/mydom-address-result.json
```

Перед публикацией проверяйте счётчики загрузки, ошибки, изменения типов и номеров. Скрипт построения отказывается публиковать неполную загрузку страниц без явного `--allow-partial`. Даже полностью скачанный вторичный справочник не означает полноту ГАР.
