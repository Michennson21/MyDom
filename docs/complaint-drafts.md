# Подготовка обращений

Модуль `issues.js` работает локально без сервера и не отправляет обращения. В разделе «Решить проблему» доступны шаблоны по характеру проблемы, редактирование адресата и текста, сохранение внутри выбранной квартиры, повторное открытие, печать, HTML и TXT. PDF создаётся через системное меню печати там, где браузер поддерживает сохранение. HTML содержит только экранированный текст и стили печати A4, без скриптов и сетевых запросов.

Адресат: название УК по текущему сопоставлению или ручному выбору; для поставщика — единственное название из QR-квитанций выбранного лицевого счёта, иначе название услуги. Это подсказка, не проверка надлежащего ответчика. Пользователь сверяет её с договором/квитанцией. При нескольких лицевых счетах приложение не выбирает один наугад. ФИО и адрес для ответа обязательны. Паспорт и сведения о праве собственности не запрашиваются. Приложения перечисляются, но файлы пользователь передаёт адресату самостоятельно.

Старые обращения открываются в форме для дополнения. Записи сохраняются в прежнем ключе `mydomResidentIssues`, поэтому сохраняется разделение квартир и существующая серверная схема. Отметка «не отправлено» остаётся после выгрузки и печати. При ошибке хранилища текст остаётся в редакторе, состояние в памяти не подменяется успешным сохранением.

## Основания формулировок

Проверено 11.10.2026. Шаблон описывает факты со слов пользователя и содержит просьбы о проверке. Он не устанавливает факт нарушения, размер ущерба или безусловное право на перерасчёт. Универсальный срок ответа по 59-ФЗ и штрафы автоматически не подставляются. Для «Другое», расчётов, платежей и счётчиков используется нейтральный запрос без заранее выбранной нормы, поскольку условия различаются по услуге и договору.

Объявление об отключении не блокирует подготовку обращения. При выборе аварийной ситуации отображается напоминание о 112; документ не заменяет экстренный вызов.

## Проверка

`NODE_PATH=<путь к playwright> QR_TEST_BROWSER=<путь к Chromium> node tests/issues.browser.cjs`

Проверяются шаблоны, подсказка адресата, редактирование, сохранение и перезагрузка, выгрузки HTML/TXT, документ в окне печати, экранирование HTML, сбой хранилища, старые обращения, ширина экрана и раздельное хранение квартир. Реальную печать, системное меню сохранения PDF и поведение standalone-PWA на iPhone следует проверить на устройстве.

## Описание своими словами и официальный текст

Исходное поле «Что произошло» сохраняется только в карточке и не копируется в документ. Категория определяет типовую просьбу; для перерасчёта с упоминанием показаний счётчика добавляется запрос проверки показаний. Это локальные шаблоны, не свободное юридическое перефразирование произвольного рассказа. Даты, суммы, показания и обстоятельства не выдумываются: пользователь проверяет и дополняет их в редакторе. Старые сохранённые документы не изменяются автоматически; кнопка «Сформировать заново» позволяет заменить текст после подтверждения, затем сохранить новую версию.

## Вопросы и подтверждающие документы (2026-10-11)

Новый сценарий `issue-guide.js`: проблема → услуга → причина (для перерасчёта/счётчика) или наблюдаемый масштаб перебоя → уточнение выставляющей счёт стороны для вопросов о расчётах → предложенный адресат → форма и список подтверждений → редактор документа.

Адресат — рекомендация для начала обращения, а не юридическое установление ответственности. Используются только сохранённые счета/квитанции текущего помещения и сведения об управляющей организации. Несколько подходящих организаций или счетов требуют выбора; неизвестное полное название заполняется пользователем. Название и счёт можно исправить. При ручном выборе другой организации чужой лицевой счёт не переносится. Получатель платежа может отличаться от исполнителя услуги. Для холодной воды адресат закреплён за Водоканалом, для горячей воды и отопления — за НТС, независимо от сохранённых счетов. Выбор между ними и УК не предлагается. УК остаётся адресатом по общему имуществу; для других услуг маршрут уточняется отдельно. Для электросчётчиков отдельно указана необходимость уточнить ответственную организацию.

Подсказки различаются для начислений, платежа, перерасчёта по показаниям/качеству/отсутствию/ошибке, поломки/поверки/замены/передачи показаний счётчика, общего имущества. Подтверждения не обязательны для создания заявления. Чекбоксы изначально выключены; отмеченные названия дополняют редактируемый перечень приложений. Снятие отметки удаляет только соответствующую строку. Это список подготовленных документов: загрузки фото, хранения файлов или автоматической отправки в этой версии нет.

Ответы на вопросы сохраняются в поле `guide` локального обращения и дают типовой контекст в документе. Свободное описание по-прежнему сохраняется только в карточке, без дословной вставки в заявление. Существующие обращения не перезаписываются; печать/HTML/TXT используют сохранённую редакцию. Данные изолируются существующим механизмом квартир. Сетевых запросов для подбора документов нет.

При временном отсутствии приложение не обещает перерасчёт: условия зависят от услуги и обстоятельств; для ТКО не предлагается акт о технической невозможности установки счётчика. Для остальных услуг такой акт показан условно, а не как универсальное требование. Для поверки рекомендуются имеющиеся сведения ФГИС «Аршин», без обязательного бумажного свидетельства. Фото текущих показаний не представляется доказательством прошлых. Не предлагается вскрывать счётчик или снимать пломбы.

## Уточнение маршрута и возврата (2026-10-11)

На каждом шаге после первого есть «Назад». Из формы можно вернуться к адресату и предыдущим вопросам; из редактора — к форме. Введённые контакты, описание и приложения сохраняются в памяти текущего сценария. Возврат с неизменёнными данными сохраняет ручные правки текста. Если изменены данные, влияющие на документ, замена ручных правок требует подтверждения. Начало нового обращения сбрасывает временный сценарий. Старые сохранённые обращения остаются читаемыми, история вопросов восстанавливается из `guide`.

Холодная вода → Водоканал; горячая вода/отопление → НТС (ООО «Нальчикские тепловые сети», название из существующего справочника приложения). Это настройка маршрутизации приложения по уточнению пользователя, а не автоматическая проверка границ ответственности по конкретному договору. Наличие лицевого счёта не обязательно для появления адресата; при нескольких счетах выбирается только счёт соответствующей услуги. Поддерживается сокращение «НТС». При смене услуги не переносятся адресат/лицевой счёт прежнего поставщика. Название адресата остаётся редактируемым в форме.


## Единая маршрутизация всех услуг (2026-10-11, v46)

Удалены вопрос о стороне, выставляющей квитанцию, и кнопка выбора другой организации во всех ветках. Алгоритм определяет одного адресата по услуге, типу проблемы и данным жилья. На экране адресата пользователь продолжает подготовку; если счетов несколько — выбирает нужный счёт той же услуги. При неизвестной услуге/УК предлагается заполнить недостающие сведения в форме, без списка произвольных организаций. Редактирование реквизитов документа сохранено.

| Услуга / ситуация | Адресат по умолчанию |
| --- | --- |
| Холодная вода | Водоканал |
| Горячая вода / отопление | НТС |
| Газ: расчёты, платежи, передача показаний | ООО «Газпром межрегионгаз Нальчик» |
| Газ: перебой, поломка, поверка/замена счётчика | АО «Газпром газораспределение Нальчик» для первичного обращения и организации технических действий |
| Электричество: расчёты, платежи, показания, счётчик квартиры в МКД | ПАО «ЕГП», филиал «Каббалкэнергосбыт» |
| Электричество: перебой сети, работы со счётчиком частного дома | ПАО «Россети Северный Кавказ», филиал «Каббалкэнерго»; обслуживающую сеть сверяют по договору |
| Вывоз отходов и текущие начисления ТКО | МУП «Экотехпром» |
| Общее имущество / содержание дома | УК из сохранённых данных дома |

Это начальный маршрут обращения, не доказательство ответственности конкретного исполнителя за неисправность. При отсутствии адреса технический вопрос электросчётчика не получает выдуманного адресата. Получатель старой квитанции не заменяет автоматически актуальную организацию; по старому периоду реквизиты проверяют отдельно. По газу сохраняется предупреждение о 104/112, заявление не является аварийным вызовом. Поверку не отождествляем с демонтажом: газораспределение организует технические работы, метрологическая поверка выполняется уполномоченной организацией.

Фильтры счетов разделяют электричество и теплоснабжение. Для ТКО/содержания дома убраны причины перерасчёта по показаниям и документы счётчика; для содержания дома убрано временное отсутствие. По невывозу предлагаются фото контейнеров и даты. В шаблоне ошибки начисления ТКО/содержания не запрашиваются показания приборов.
