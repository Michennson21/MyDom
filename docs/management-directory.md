# Справочник управляющих организаций

Снимок от 09.10.2026: 32 организации с ИНН и 209 записей «адрес дома → организация» из открытых вторичных каталогов. В интерфейсе к списку добавляются уникальные прежние организации из приложения. Это не полный список всех УК/ТСЖ Нальчика и не актуальная выгрузка лицензий ГИС ЖКХ.

## Происхождение

Есть опубликованные адреса офисов и телефоны двух организаций; они помечены как сведения каталога, а не подтверждённые актуальные диспетчерские. Телефон Эстетики отсутствует и не выдуман.
- Первые 30 карточек списка Dominfo: названия и ИНН, без автоматического присвоения их домам. ИНН дополнены ведущим нулём до десяти цифр; контрольные цифры проверены тестами. Одна запись пересекается с тремя детальными каталогами, итог — 32 организации с ИНН. Это ручной исходный снимок `scripts/management-directory-seed.json`, не загрузка остальных 67 карточек.
- Прежние `orgMap` и `currentOrgMap` приложения сохранены как записи с неподтверждённой актуальностью. Более новые прежние записи имеют приоритет над старым словарём внутри этого слоя. При расхождении с новым каталогом победитель автоматически не выбирается.
- Периоды 24.06.2026–23.06.2027 внесены только для Калинина, 75 и Щаденко, 20А, где они явно приведены в карточках домов. Для остальных адресов период неизвестен, а дата загрузки не означает начало управления.

## Поведение

Сравнение адресов учитывает тип улицы, регистр, ё/е, букву после дефиса и разные написания «корпус». Дробь и корпус не приравниваются: 10/1 не равно 10к1. Точное совпадение даёт подсказку по каталогу с пометкой «требует проверки», не подтверждение договора или лицензии. Разные организации для одного дома дают статус конфликта. Неполные сведения не заменяются догадками. Истёкшие/будущие явно заданные периоды исключаются из текущего сопоставления.

Частным домам и СНТ организация автоматически не назначается. В разделе «Мой дом» пользователь может выбрать организацию по имени/ИНН или ввести название вручную. Выбор сохраняется внутри `mydomAddress.managementOverride` и активной квартиры `mydomApartmentsV1`, попадает в существующее серверное сохранение. Другие квартиры, счета и начисления не изменяются. Ручной выбор помечается «Указано вами». Для возврата выбрать «Определять по адресу» и сохранить.

Старые подписи «Подтверждено»/«проверенная база» заменяются на реальные статусы во всех карточках управляющей организации. Старое значение адреса не стирается автоматически; отображение пересчитывается из текущей базы.

## Обновление

```sh
python3 scripts/refresh-management.py
```

Обновляет три детальных каталога, проходя опубликованные страницы, и объединяет их с исходным списком организаций. При ошибке загрузки новый JS не записывается. `--use-cache` — только для воспроизводимой разработки с уже скачанными страницами в `/tmp/management-pages`, не для актуализации; дата сборки не является датой обновления источника. Перед публикацией нужно проверить изменения, конфликты и периоды. Планировщик обновления и официальная интеграция не включены.

```sh
node --test tests/management.test.cjs
```

Браузерный тест дополнительно проверяет ручной выбор, перезагрузку, переключение двух квартир и возврат к автоматическому определению без потери записей.
