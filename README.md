# Мой дом — Нальчик

Статическое приложение для личных лицевых счетов, начислений, показаний и подготовки обращений. Данные сохраняются в localStorage текущего браузера. Передача поставщикам и оплата пока не подключены.

## Версия 0.25: QR квитанций

На главной и в разделе «Начисления» доступна кнопка чтения QR. Можно включить камеру или выбрать фотографию кода. Обработка выполняется локально через включённую в репозиторий jsQR 1.4.0 (лицензия Apache-2.0 в `vendor/jsQR-LICENSE.txt`). Камера требует HTTPS или localhost.

Поддержаны текстовые платёжные QR ST00011 (Windows-1251) и ST00012 (UTF-8). `Sum` переводится из копеек в рубли. `PersAcc` используется как лицевой счёт жильца; `PersonalAcc` показывается только как банковский счёт получателя. Поля разбираются без учёта регистра. Если периода, суммы или лицевого счёта нет, их нужно ввести вручную. Услугу пользователь выбирает сам, затем подтверждает реквизиты и адрес.

Ссылочные QR (включая СБП), фискальные QR чеков и другие форматы не заполняют начисление и не открывают ссылки автоматически. Сохранение начисления не выполняет платёж. Распознавание текста квитанций удалено. Ранее сохранённые данные не удаляются.

## Локальная проверка

```sh
python -m http.server 8765
node --test tests/qr.test.cjs
```

Откройте http://localhost:8765. Для проверки телефона используйте HTTPS-размещение. Проверьте QR своей квитанции, исправьте отсутствующие поля и убедитесь, что сумма и лицевой счёт совпадают с оригиналом.

При обновлении service worker меняйте имя кеша и включайте новые файлы приложения в список CORE. Изменение версии не очищает localStorage.

## Версия 0.26: фотографии квитанций

Фото проверяется в нескольких масштабах и перекрывающихся участках с сохранением деталей небольшого QR. После jsQR выполняется вторая попытка через ZXing 0.21.3 (Apache-2.0, `vendor/zxing-LICENSE.txt`). Между попытками интерфейс остаётся доступным; закрытие окна или выбор нового фото отменяет предыдущий поиск. Камера запрашивает разрешение до 1920×1080, если устройство его поддерживает. Версия считывателя видна в его заголовке.

Регрессионная проверка фото (необязательные зависимости для разработки):

```sh
npm install --no-save playwright qrcode pngjs
npx playwright install chromium
node tests/photo-regression.cjs
```

Проверка создаёт QR на изображении 6000×4000, подтверждает отказ прежнего алгоритма и успешное чтение новым, а также проверяет кириллицу вторым декодером и отмену поиска. Реальные снимки с бликами, расфокусировкой или повреждённым кодом требуют отдельной проверки.
